市区町村コード情報取得API仕様
​
説明
​

国土交通DPFで利用する市区町村コードとコードに対応する市区町村名の一覧を取得するAPIです。

GraphQL定義
​

GraphQLの定義を以下に示します。

GraphQL
type Query {
  municipalities(
    muniCodes: [Any], 
    prefCodes: [Any]
  ): [MunicipalityClass]
}
パラメータ
​

各パラメーターの詳細を以下に示します。

引数名	タイプ	説明
muniCodes	Any	情報を取得する市区町村コードです。
文字列または整数として設定します。
prefCodes	Any	市区町村情報を取得する都道府県コードです。コードで指定した都道府県に含まれる市区町村情報を取得します。
文字列または整数として設定します。

muniCodesとprefCodesで情報の取得範囲を指定しない場合は全市区町村情報を取得します。

結果
​

市区町村情報取得APIの結果としてMunicipalityClassの配列を返します。
